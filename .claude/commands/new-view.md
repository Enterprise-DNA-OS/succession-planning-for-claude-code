# Add a view

Read CLAUDE.md. Confirm the question and authorised audience. Add a read-only query to views.json using the established SQL views. Avoid names and detailed assessments where aggregate counts suffice. Run `npm run view`, inspect the HTML and test that the result matches the CLI. Reports are private snapshots. Never publish or send one without the operator's authorisation.
