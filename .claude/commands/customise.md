# Make it yours

Read CLAUDE.md and inspect the existing migration, CLI and tests. Ask for the exact business rule if it is missing. Back up the data with `/export`. Add a new numbered migration rather than editing an applied migration. For a freshness change, update the named settings row with a documented business reason; never describe it as a legal deadline. Run `npm run migrate`, update commands, import mapping and documents if affected, and run `npm test` against disposable data. Present the changed behaviour and evidence. Do not add protected personal traits, automated promotion decisions or a public staff interface.
